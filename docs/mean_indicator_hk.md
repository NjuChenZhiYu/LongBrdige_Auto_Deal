# 港股均线衍生指标与多周期共振量化规范 (EMA MTF & V-Reversal Spec)

## 1. 核心系统目标 (Core Objectives)
本模块为 `Global_Quant_System` 的核心数学引擎。系统需抛弃传统的简单移动平均线（SMA），全面采用**指数平滑移动平均线 (EMA)** 作为底层传感器。通过计算均线的一阶导数（速度）与二阶导数（动能加速度），结合**多周期共振 (MTF)** 保障右侧交易胜率，并创新性地引入 **12% 乖离率 (Bias)** 结合动能反转，以中和右侧指标的滞后性，精准捕捉极度超跌后的 V 型反弹左侧买点。

## 2. 数学建模与底层计算 (Mathematical Engine)
设 $P_{historical}(t)$ 为历史每日收盘价，$P_{realtime}$ 为当日盘中实时价格。系统需使用 Pandas 的 `ewm` (Exponential Weighted Functions) 进行向量化运算，同时**必须将实时价格拼接到历史 K 线数据的末尾**（如果当日 K 线未收盘），以确保最新价格拥有最高权重，反映当下最真实的盘面。

### 2.1 指数平滑均线 (EMA)
构建短、中两个时间窗口的价值防线：
* **短期传感器**：$EMA_5(t)$
* **中期价值中枢**：$EMA_{20}(t)$
*(注意：计算 $EMA(t)$ 时，最新的数据点必须使用 $P_{realtime}$，而不是前一日收盘价)*

### 2.2 趋势速度 / 一阶导数 (Velocity)
将变化率百分比化，消除标的间的绝对价格量纲差异，反映趋势的运行方向与速率。
* **短期速度**：$$V_5(t) = \frac{EMA_5(t) - EMA_5(t-1)}{EMA_5(t-1)} \times 100\%$$
* **中期速度**：$$V_{20}(t) = \frac{EMA_{20}(t) - EMA_{20}(t-1)}{EMA_{20}(t-1)} \times 100\%$$

### 2.3 趋势动能 / 二阶导数 (Acceleration)
衡量速度的边际变化率，用于判断当前趋势是在“加速”还是在“踩刹车”。
* **短期加速度**：$$A_5(t) = V_5(t) - V_5(t-1)$$

### 2.4 实时均值引力 / 乖离率 (Real-time Bias)
计算当前**实时价格**偏离中期价值中枢的距离，作为测算“弹簧拉力”的核心物理量。
* **乖离率公式**：$$Bias_{20}(t) = \frac{P_{realtime} - EMA_{20}(t)}{EMA_{20}(t)} \times 100\%$$

## 3. 量化标签生成规则 (Tagging Logic)
系统需在每日盘中触发时，根据包含实时价格的数学计算结果，按优先级生成以下策略标签，并输出至 AI 研报中：

### 3.1 左侧中和策略：V型反转与极限摸顶 (最高优先级)
用于捕捉极端行情下的第一波 10% 暴力修复利润，克服右侧系统的滞后性。
* **【极度超跌：V型反转预备】**：
    * **触发条件**：$Bias_{20} \le -12.0\%$ 且 $A_5 > 0$
    * **逻辑归因**：价格已暴跌至严重超卖区间（弹簧拉力极强），且短期下跌速度开始放缓（二阶导转正，空头踩下刹车）。极大概率迎来向 $EMA_{20}$ 靠拢的暴力反弹。
* **【极度超买：估值透支预警】**：
    * **触发条件**：$Bias_{20} \ge 12.0\%$ 且 $A_5 < 0$
    * **逻辑归因**：价格狂飙脱离基本面中枢，且上涨加速度开始转负，多头动能枯竭，随时面临均值回归的砸盘风险。

### 3.2 右侧趋势策略：多周期共振 (MTF)
用于在常态市场中进行胜率极高的顺势判定。
* **【主升浪加速：长短共振】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$ 且 $A_5 > 0$
    * **逻辑归因**：中期趋势向好，短期趋势向好，且处于加速爆发期，属于最强看多信号。
* **【主升浪降速：高位震荡/诱多】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$，但 $A_5 < 0$
    * **逻辑归因**：虽然均线绝对值仍在上涨，但上涨速度已严重衰减，主力可能在拉高出货或面临高位换手。
* **【主跌浪加速：空头长短共振】** (补充)：
    * **触发条件**：$V_{20} < 0$ 且 $V_5 < 0$ 且 $A_5 < 0$
    * **逻辑归因**：大势向下，短期也向下，且下跌正在加速（猛踩油门倒车），绝对空头压制，系统提示坚决规避。
* **【跌势放缓：左侧建仓观察区】** (补充)：
    * **触发条件**：$V_{20} < 0$ 且 $V_5 < 0$ 且 $A_5 > 0$
    * **逻辑归因**：虽然仍处于下跌通道，但下跌速度开始收敛（二阶导转正）。这往往是 V 型反转的前兆，可结合资金流向观察主力是否在暗中吸筹。

### 3.3 趋势反转策略：均线拐点与交叉 (补充)
用于捕捉趋势刚刚发生反转的早期信号。
* **【短期趋势转多：均线金叉预备】** (补充)：
    * **触发条件**：$V_{20} < 0$（或方向不明）但 $V_5 > 0$
    * **逻辑归因**：中期趋势仍在调整，但短期均线已率先抬头向上。这意味着短线有资金介入，可能演变为一波反弹或反转金叉。
* **【短期趋势转空：均线死叉预备】** (补充)：
    * **触发条件**：$V_{20} > 0$ 但 $V_5 < 0$
    * **逻辑归因**：中期趋势依然向好，但短期资金开始撤离，均线掉头向下。这可能是上升途中的洗盘回调，也可能是见顶死叉的前奏。

1.  **修改核心函数**：在 `src/analysis/futu_math_indicator.py` 中更新核心计算函数为 `calculate_ema_derivatives(df: pd.DataFrame, current_price: float) -> dict:`。
2.  **数据拼接逻辑**：如果 `df` 中最后一行的数据日期不是今天，则需要将 `current_price` 作为一个新行（代表今天的最新收盘价）拼接到 `df` 中，或者直接用 `current_price` 更新今天已有的收盘价，确保 `EMA` 计算包含了最新的价格动量。
3.  **核心代码实现要求**：
    ```python
    import pandas as pd

    # 0. 拼接或更新最新价格
    # 假设 df 已经包含历史数据，需处理当前价格 current_price
    # df 最后一行的 close 会被赋予或更新为 current_price 以反映盘中实时状态
    
    # 1. 计算机构级 EMA
    df['EMA5'] = df['close'].ewm(span=5, adjust=False).mean()
    df['EMA20'] = df['close'].ewm(span=20, adjust=False).mean()

    # 2. 计算一阶导数 V (百分比变化率)
    df['V5'] = df['EMA5'].pct_change() * 100
    df['V20'] = df['EMA20'].pct_change() * 100

    # 3. 计算二阶导数 A (速度的差分)
    df['A5'] = df['V5'].diff()

    # 4. 计算实时 Bias 乖离率
    df['Bias20'] = (df['close'] - df['EMA20']) / df['EMA20'] * 100
    ```
4.  **标签判定引擎**：获取 DataFrame 最后一行（最新数据），使用 `if-elif` 逻辑树匹配第 3 节中的规则。**务必优先判断 3.1 节的 Bias 极限值场景**，若未触发左侧信号，再进行 3.2 节的右侧共振判定。
5.  **研报调用方修改**：在 `src/services/llm_analyst.py` 中调用该函数时，必须将当前盘中价格 `stock['last_price']` 传入：
