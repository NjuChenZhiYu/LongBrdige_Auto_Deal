# 港股均线衍生指标与多周期共振量化规范 (EMA MTF & V-Reversal Spec)

## 1. 核心系统目标 (Core Objectives)
本模块为 `Global_Quant_System` 的核心数学引擎。系统需抛弃传统的简单移动平均线（SMA），全面采用**指数平滑移动平均线 (EMA)** 作为底层传感器。通过计算均线的一阶导数（速度）与二阶导数（动能加速度），结合**多周期共振 (MTF)** 保障右侧交易胜率，并创新性地引入 **12% 乖离率 (Bias)** 结合动能反转，以中和右侧指标的滞后性，精准捕捉极度超跌后的 V 型反弹左侧买点。

## 2. 数学建模与底层计算 (Mathematical Engine)
设 $P(t)$ 为当日收盘价。系统需使用 Pandas 的 `ewm` (Exponential Weighted Functions) 进行向量化运算，确保最新价格拥有最高权重。

### 2.1 指数平滑均线 (EMA)
构建短、中两个时间窗口的价值防线：
* **短期传感器**：$EMA_5(t)$
* **中期价值中枢**：$EMA_{20}(t)$

### 2.2 趋势速度 / 一阶导数 (Velocity)
将变化率百分比化，消除标的间的绝对价格量纲差异，反映趋势的运行方向与速率。
* **短期速度**：$$V_5(t) = \frac{EMA_5(t) - EMA_5(t-1)}{EMA_5(t-1)} \times 100\%$$
* **中期速度**：$$V_{20}(t) = \frac{EMA_{20}(t) - EMA_{20}(t-1)}{EMA_{20}(t-1)} \times 100\%$$

### 2.3 趋势动能 / 二阶导数 (Acceleration)
衡量速度的边际变化率，用于判断当前趋势是在“加速”还是在“踩刹车”。
* **短期加速度**：$$A_5(t) = V_5(t) - V_5(t-1)$$

### 2.4 均值引力 / 乖离率 (Bias)
计算当前价格偏离中期价值中枢的距离，作为测算“弹簧拉力”的核心物理量。
* **乖离率公式**：$$Bias_{20}(t) = \frac{P(t) - EMA_{20}(t)}{EMA_{20}(t)} \times 100\%$$

## 3. 量化标签生成规则 (Tagging Logic)
系统需在每日快照落库时，根据上述数学计算结果，按优先级生成以下策略标签，并输出至 AI 研报中：

### 3.1 左侧中和策略：V型反转与极限摸顶 (最高优先级)
用于捕捉极端行情下的第一波 10% 暴力修复利润，克服右侧系统的滞后性。
* **【极度超跌：V型反转预备】**：
    * **触发条件**：$Bias_{20} \le -12.0\%$ 且 $A_5 > 0$
    * **逻辑归因**：价格已暴跌至严重超卖区间（弹簧拉力极强），且短期下跌速度开始放缓（二阶导转正，空头踩下刹车）。极大概率迎来向 $EMA_{20}$ 靠拢的暴力反弹。
* **【极度超买：估值透支预警】**：
    * **触发条件**：$Bias_{20} \ge 12.0\%$ 且 $A_5 < 0$
    * **逻辑归因**：价格狂飙脱离基本面中枢，且上涨加速度开始转负，多头动能枯竭，随时面临均值回归的砸盘风险。

### 3.2 右侧趋势策略：多周期共振 (MTF)
用于在常态市场中进行胜率极高的顺势判定。
* **【主升浪加速：长短共振】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$ 且 $A_5 > 0$
    * **逻辑归因**：中期趋势向好，短期趋势向好，且处于加速爆发期，属于最强看多信号。
* **【顶部诱多：动能背离】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$，但 $A_5 < 0$
    * **逻辑归因**：虽然均线绝对值仍在上涨，但上涨速度已严重衰减，主力可能在拉高出货。
* **【主跌浪向下：空头排列】**：
    * **触发条件**：$V_{20} < 0$ 且 $V_5 < 0$
    * **逻辑归因**：大势向下，短期也向下，绝对空头压制，系统提示规避。

## 4. 给 Trae 的开发指令 (Implementation Directives)

1.  **新建/修改模块**：在 `src/analysis/futu_math_indicator.py` 中编写核心计算函数 `calculate_ema_derivatives(df: pd.DataFrame) -> dict:`。
2.  **核心代码实现要求**：
    ```python
    import pandas as pd

    # 1. 计算机构级 EMA
    df['EMA5'] = df['close'].ewm(span=5, adjust=False).mean()
    df['EMA20'] = df['close'].ewm(span=20, adjust=False).mean()

    # 2. 计算一阶导数 V (百分比变化率)
    df['V5'] = df['EMA5'].pct_change() * 100
    df['V20'] = df['EMA20'].pct_change() * 100

    # 3. 计算二阶导数 A (速度的差分)
    df['A5'] = df['V5'].diff()

    # 4. 计算 Bias 乖离率
    df['Bias20'] = (df['close'] - df['EMA20']) / df['EMA20'] * 100
    ```
3.  **标签判定引擎**：获取 DataFrame 最后一行（最新数据），使用 `if-elif` 逻辑树匹配第 3 节中的规则。**务必优先判断 3.1 节的 Bias 极限值场景**，若未触发左侧信号，再进行 3.2 节的右侧共振判定。
4.  **研报数据注入**：将最终命中的 `【标签名称】` 以及具体的 `V5, A5, Bias20` 数值打包返回，供 LLM 在生成最终的 Markdown 研报时作为“数学技术面”段落的核心依据。
