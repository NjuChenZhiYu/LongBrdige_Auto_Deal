# 单股 LLM 研报 Prompt 与评分改进计划

## 背景问题

当前单股研报把“资产故事评分”和“当前可交易评分”混在一个 `量化综合做多指数` 中，导致模型容易被热门赛道、AI 概念、资金净流入和事件叙事带偏。

典型问题是 `HK.02513 智谱`：输入数据已经明确出现 `主升浪降速：高位震荡/诱多 + 放量`，并提示“派发风险增强”，同时估值 PS 远高于可比公司、财务仍处亏损状态，但最终报告仍给出 `82/100`。这说明当前 prompt 缺少硬性风控约束，也缺少对“赛道相关性、财务兑现、估值合理性、事件真实性、盘口行为”之间的交叉验证。

## 核心原则

1. 好赛道不等于好基本面。
   - “AI、机器人、创新药、火箭”等只代表赛道或叙事相关性。
   - 基本面必须同时看业务真实性、收入增长、盈利路径、现金流、付费意愿、订单/客户质量和估值兑现难度。
   - 如果只有概念相关，没有财务和商业化支撑，应判定为“叙事强、基本面弱”。

2. 估值不能只给“稀缺性溢价”或“严重低估”。
   - 必须允许第三种结论：估值远离业绩支撑、叙事溢价已透支。
   - 对 PS 极端高、亏损扩大、收入规模不足的公司，应显著降低基本面/估值得分。

3. 事件催化必须可验证。
   - 股价大涨不一定是坏事，关键看是否有真实事件支撑。
   - 例如创新药临床重大成功、监管批准、重大订单、财报超预期，可以支撑突破。
   - 如果只是概念炒作、市场传闻、模糊战略表态，不能作为高分催化。

4. 高位派发是交易风控一票否决项。
   - `主升浪降速/高位震荡/诱多 + 放量 + 高位 + 极端换手/成交额` 不应只是趋势筹码扣几分。
   - 一旦触发，应强制把当前做多指数封顶，并将结论改为“不追高/减仓/等待回落确认”。

## 现有 Prompt 的主要缺陷

### 1. 五因子权重不适合交易风控

当前结构为：

```text
基本面30 + 关联估值20 + 流动性25 + 趋势筹码15 + 事件催化10 = X/100
```

问题：

- 趋势筹码只有 15 分，即使出现明显高位派发，模型也可能只扣 5-10 分。
- 基本面和估值合计 50 分，容易让“好赛道叙事”压过当前交易风险。
- 流动性 25 分过高，且没有强制区分“健康承接”和“高位出货换手”。
- 事件催化 10 分缺少真实性过滤，容易把概念热度当催化。

### 2. 基本面段落过度偏向叙事

当前 `买方四大公理映射` 强调出海、AI 层级、老龄化和效率提升，并要求“双核驱动”给予极高溢价。这会诱导模型把“符合热门赛道”直接等同于“高质量基本面”。

应改为：

```text
基本面质量 = 赛道关联性 + 业务真实性 + 财务兑现 + 估值合理性
```

其中：

- 赛道关联性只证明“有想象空间”。
- 财务兑现决定“能否支撑市值”。
- 估值合理性决定“当前价格是否透支”。
- 三者不一致时，必须显式写出割裂点。

### 3. 流动性段落没有风险语义

当前 prompt 要求根据资金方向、成交额、换手率判断流动性贡献，但没有说明：

- 高位巨量成交不等于健康承接。
- 高位极端换手可能是筹码派发。
- 主力净流入也可能发生在诱多、对倒或分歧换手阶段，不能自动利多。

应要求模型结合：

- 当日涨跌幅
- 日内位置
- 30/90/180 日空间位置
- `tag_today`
- `bias20`
- 成交额/换手率相对历史倍数
- 是否存在真实事件催化

综合判断是“健康突破承接”还是“高位派发换手”。

## 新评分框架建议

建议将单一做多指数拆成两层：

### 第一层：资产质量评分

用于回答“这个公司长期是否值得跟踪”。

```text
资产质量评分 = 赛道关联性20 + 业务真实性20 + 财务兑现25 + 估值合理性20 + 事件/产业催化15
```

评分解释：

- 赛道关联性：是否处于高成长行业，是否真正位于产业链关键环节。
- 业务真实性：产品是否真实落地，客户/订单/商业模式是否清晰。
- 财务兑现：收入增长、毛利、亏损、现金流、付费意愿是否支撑故事。
- 估值合理性：PS/PE/PB/市值与可比公司及自身收入规模是否匹配。
- 事件/产业催化：是否有可验证、足够重大的新增信息。

### 第二层：当前交易评分

用于回答“现在能不能做多/追高/加仓”。

```text
当前交易评分 = 资金方向20 + 流动性承接20 + 趋势筹码25 + 位置风险20 + 事件确认15
```

评分解释：

- 资金方向：主力/整体资金是否同向，是否持续。
- 流动性承接：成交额和换手率是健康承接还是高位分歧。
- 趋势筹码：`tag_today`、POC、筹码分布、10 日风险收益。
- 位置风险：30/90/180 日分位、bias20、日内位置。
- 事件确认：本轮上涨是否有真实事件支撑。

最终 `量化综合做多指数` 应优先使用“当前交易评分”，而不是长期资产质量评分。长期资产质量可以作为附属结论展示。

## 一票否决规则

### 高位派发否决

若满足以下条件，应触发“高位派发/逃顶风险”：

```text
tag_today 包含 “主升浪降速” 或 “高位震荡/诱多”
且 tag_today 包含 “放量” 或 成交额/换手率显著偏高
且 30/90/180 日至少两个窗口 position_pct >= 65
且 bias20 >= 10 或 当日涨幅 >= 10
且没有明确、可验证、足够重大的事件催化
```

触发后：

- 当前交易评分封顶 `55/100`。
- 若同时出现极端估值、财务亏损、PS 远高于可比公司，则封顶 `45/100`。
- 第一结论必须包含“不追高/减仓/等待回落确认”。
- 流动性不得高于 `10/20`。
- 趋势筹码不得高于 `8/25`。
- 位置风险不得高于 `5/20`。

### 财务与估值脱锚否决

若满足以下条件，应触发“基本面兑现不足”：

```text
公司处于热门赛道
但收入规模小或增长无法覆盖市值预期
且 EPS/现金流/净资产质量较弱
且 PS 明显高于全球可比公司
```

触发后：

- 资产质量评分不能因赛道直接高分。
- 基本面结论必须写出“赛道叙事强，但财务兑现不足/估值透支”。
- 若同时触发高位派发，当前交易评分应进入低分区间。

### 真实事件豁免

如果出现高位大涨，但存在明确事件支撑，可以不直接一票否决。

有效事件包括：

- 创新药临床关键节点成功、监管批准、重大适应症进展。
- 重大订单、合同、客户突破，且金额足以影响收入预期。
- 财报收入/利润/现金流显著超预期。
- 政策或产业事件对公司业务有直接、可量化影响。

无效事件包括：

- 模糊概念、市场传闻、媒体热度。
- 公司宣布进入热门方向但没有收入、订单或技术验证。
- 仅因板块上涨或题材轮动造成的情绪拉升。

## Prompt 改造建议

### 核心结论段

将原来的单一分数要求改为：

```text
第一行固定格式：
【当前交易做多指数：评级 (X/100) - 一句话方向总结】

第二行必须列出：
当前交易评分 = 资金方向20 + 流动性承接20 + 趋势筹码25 + 位置风险20 + 事件确认15 = X/100

第三行必须列出：
资产质量评分 = 赛道关联性20 + 业务真实性20 + 财务兑现25 + 估值合理性20 + 事件/产业催化15 = Y/100

若当前交易评分与资产质量评分背离，必须解释背离原因。
```

### 基本面与估值段

新增要求：

```text
必须区分“赛道相关性”和“财务兑现”：
- 赛道好只能说明上限，不能直接等于基本面高分。
- 若财务数据、收入规模、盈利路径、现金流或付费意愿无法支撑当前市值，必须降低基本面结论。
- 若 PS 明显高于可比公司，必须明确写出“估值远离业绩支撑/叙事溢价透支”，不得只写“稀缺性溢价”。
```

### 流动性证据链段

新增要求：

```text
成交额/换手率偏高必须先判断位置：
- 低位放量：可能是承接或反转。
- 中位放量：可能是分歧换手。
- 高位放量：优先怀疑派发或诱多。

若 tag_today 已提示高位派发，流动性不能按健康承接给高分。
```

### 技术面证据链段

新增要求：

```text
若出现“主升浪降速/高位震荡/诱多 + 放量”，必须执行一票否决检查。
若同时处于多周期高位、bias20 明显正乖离、成交额/换手率极端偏高，必须将当前交易评分封顶，并明确给出减仓/不追高计划。
```

### 事件催化段

新增独立判断：

```text
必须判断本轮上涨是否有真实事件支撑：
- 有明确事件支撑：说明事件如何改变收入、利润、订单或估值锚。
- 无明确事件支撑：将上涨归类为情绪/题材/资金博弈，不能给高事件分。
```

## 验收样例

### HK.02513 智谱

预期输出方向：

```text
【当前交易做多指数：★★☆☆☆ (40-50/100) - 高位放量降速，疑似派发，不追高，持仓以减仓保护利润为主】
```

应体现：

- AI 赛道相关性强，但财务兑现弱。
- PS 极端高，估值远离业绩支撑。
- 高位放量降速与极端换手触发一票否决。
- 主力净流入不能抵消高位派发风险。

### HK.02590 极智嘉-W

预期输出方向：

```text
【当前交易做多指数：★★☆☆☆ (45-55/100) - 深度超跌但资金未回流，仅左侧观察】
```

应体现：

- 赛道和出海逻辑可跟踪。
- 资金持续流出、成交额偏低，不能给高交易分。
- 低位缩量不是一票否决，但需要右侧确认。

### 有真实事件支撑的强突破

例如创新药公司因临床关键数据成功大涨 10%：

预期输出方向：

```text
【当前交易做多指数：★★★☆☆/★★★★☆ - 事件真实支撑突破，但需结合估值和承接确认】
```

应体现：

- 不因涨幅大自动判定高位派发。
- 必须说明事件是否改变收入、利润、估值锚或成功概率。
- 若放量突破且位置不过度极端，可允许较高交易分。
