# 四大底层公理（买方精简版）
**标签：** `#买方底层逻辑` `#宏观公理` `#Prompt组件` `#定价内核`

## 核心定位
用于港美股硬科技/成长股的上层判断框架。目标是让 LLM 在做研报时先回答“长期赔率来自哪里”，再回答“短期交易怎么做”。

## 四条公理（可直接放入 Prompt）
1. **出海与全球化能力（中外剪刀差：成本人民币化，收益美元化）**  
   在内需偏弱周期，出海能力、全球化市占率是硬科技公司活下去并获得市场认可的首要条件。能以人民币成本组织研发和供应链、并向美元/欧元市场创汇的企业，拥有更稳的现金流质量与估值溢价。
2. **AI 产业层级与关联度（产业链上下游传导模型）**  
   不能泛泛而谈“有AI”，必须精准定位标的在AI产业链上下游的真实位置。各Tier代表产业传导的先后顺序，而非绝对的价值高低：
   * **Tier 1 (算力基建/硬件底座)**：AI产业的“卖铲人”。包括核心芯片（英伟达、海力士）、代工制造（台积电）、光模块、液冷、服务器组装等。它们最先受益于资本开支，业绩兑现最确定。
   * **Tier 2 (模型层/核心工具链/强关联组件)**：AI的“发动机与变速箱”。包括大模型厂商（OpenAI）、核心云平台，以及**高度依赖大模型生态的强关联基础设施**（如提供向量数据库、AI存储记忆组件、核心API网关的公司）。它们构建了AI的运行生态。
   * **Tier 3 (深度应用/具身智能)**：AI的“车轮与执行器”。如极智嘉、小马智行、特斯拉。它们将Tier 1/2的能力深度融合进物理世界或垂直行业，彻底重塑商业模式（实现“智力边际成本趋零”），是目前最具爆发潜力的落地层。
   * **Tier 4 (边缘应用/AI概念包装)**：传统业务的“修饰”。如部分传统SaaS、支付/金融软件（如连连数字）。仅仅是将AI作为降本增效的辅助工具（写写邮件、客服对话），而非核心商业逻辑重构。
   * **评估标准**：标的处于Tier 1/2/3，说明其处于核心传导链上，才能享受“高赔率成长期权”；处于Tier 4，只能按传统基本面估值。
3. **物理世界效率跃升（受制于资源上限）**  
   土地、能源、路网等资源有硬约束。能提升物理系统转化效率（仓储、物流、出行、能源利用）的企业，更容易获得基础设施级溢价。
4. **人口老龄化不可逆（两大刚需）**  
   长期资本会持续配置“机器替人（自动化/具身智能）”与“对抗衰老和重疾（创新药/生命科学）”两条刚需赛道。

## 关于四大公理优先级的思考（权重分配）
针对这四条公理，在实际买方评估时，权重并非均等。宏观环境和企业生命周期决定了它们的优先级：

**第一层：生存基石与现实利润（最高权重，决定下限）**
*   **1. 中外剪刀差（权重 40%）**：在当前宏观语境下，这是最能直接兑现为当期现金流的逻辑。出海能力、全球化市占率是硬科技公司活下去并获得市场认可的**首要条件**。没有这条，其他都是空中楼阁。

**第二层：远期空间与爆发力（高权重，决定上限）**
*   **2. AI产业层级与关联度（权重 30%）**：这是技术平权带来的最大红利，但必须区分标的在产业链上下游的位置。只有处于算力基建/硬件（Tier1）、模型与核心强关联组件（Tier2）或深度赋能物理世界（Tier3，如自动驾驶/机器人）的公司，才能享受“高赔率成长期权”。边缘应用或概念包装（Tier4）不能享受此溢价。

**第三层：产业必然性与长坡厚雪（中等权重，决定赛道长度）**
*   **4. 老龄化不可逆（权重 20%）**：这是不可逆的刚需底座，驱动着医疗健康和机器人（机器换人）赛道的长期增长。它是一个慢变量，但极其坚实。

**第四层：基建改造与稳健复利（基础权重，决定商业模式护城河）**
*   **3. 物理世界效率跃升（权重 10%）**：这通常涉及较重资产投入或复杂的线下履约（如仓储物流自动化、能源互联网）。它的天花板往往受限于物理定律和资本开支，属于细水长流的稳健逻辑。

**总结应用原则**：
*   **绝对核心**：1和2是决定科技股爆发力的“双核”。如果一个标的既有1（出海赚美元）又有2（AI降本），必须给予**极高溢价**（例如：极智嘉、小马智行）。
*   **安全垫**：如果只有3或4，它更偏向于“长牛/慢牛”，需要更苛刻地审视其当前的估值安全边际。

## 给 LLM 的最小使用规则
1. 必须先判断标的匹配哪几条公理，再给结论。
2. 若匹配 >=2 条且有财务/订单验证，可上调中长期评分。
3. 若仅有叙事、缺少现金流或商业化验证，必须降级为“高波动主题交易”，不得给高置信度长线结论。
4. 结论必须包含“反面证伪条件”（政策、需求、技术替代、竞争格局）。
