# 港股均线衍生指标与多周期共振量化规范 (EMA + Volume Regime Spec)

## 1. 核心系统目标 (Core Objectives)
本模块为 `Global_Quant_System` 的核心数学引擎。系统需抛弃传统的简单移动平均线（SMA），全面采用**指数平滑移动平均线 (EMA)** 作为底层传感器。通过计算均线的一阶导数（速度）与二阶导数（动能加速度），结合**多周期共振 (MTF)** 保障右侧交易胜率。

当前版本采用“双因子”口径：

1. **价格结构因子**：`V20 / V5 / A5`
2. **流动性确认因子**：`成交量 regime`（基于目标成交额 `volume_target` 与 `volume_ema5 / volume_ema20` 的相对强弱）

说明：

- `Bias20` 保留为观测指标输出，但**不再将其作为标签判定因子**。
- `tag_today` 不应只看价格，也不应只看单点成交量。
- 当前阶段**不引入换手率**：港股流通股本字段在富途快照中并非每只标的都稳定可得，且换手率本质上是对单股自比再除一个常数，对“是放量还是缩量”这种单股相对判断没有额外信息增量。
- 为避免盘中前段成交量被外推放大或缩小，本规范默认使用 **T-1 锚**；当调用方确认当天成交额已具备可比性（例如港股 15:00 后或盘后）时，允许使用当天成交额作为 `volume_target`，不做盘中折算。

## 2. 数学建模与底层计算 (Mathematical Engine)
设 $P_{historical}(t)$ 为历史每日收盘价，$P_{realtime}$ 为当日盘中实时价格。系统需使用 Pandas 的 `ewm` (Exponential Weighted Functions) 进行向量化运算，同时**必须将实时价格拼接到历史 K 线数据的末尾**（如果当日 K 线未收盘），以确保最新价格拥有最高权重，反映当下最真实的盘面。

### 2.1 指数平滑均线 (EMA)
构建短、中两个时间窗口的价值防线：
* **短期传感器**：$EMA_5(t)$
* **中期价值中枢**：$EMA_{20}(t)$
*(注意：计算 $EMA(t)$ 时，最新的数据点必须使用 $P_{realtime}$，而不是前一日收盘价)*

### 2.2 趋势速度 / 一阶导数 (Velocity)
将变化率百分比化，消除标的间的绝对价格量纲差异，反映趋势的运行方向与速率。
* **短期速度**：$$V_5(t) = \frac{EMA_5(t) - EMA_5(t-1)}{EMA_5(t-1)} \times 100\%$$
* **中期速度**：$$V_{20}(t) = \frac{EMA_{20}(t) - EMA_{20}(t-1)}{EMA_{20}(t-1)} \times 100\%$$

### 2.3 趋势动能 / 二阶导数 (Acceleration)
衡量速度的边际变化率，用于判断当前趋势是在“加速”还是在“踩刹车”。
* **短期加速度**：$$A_5(t) = V_5(t) - V_5(t-1)$$

### 2.4 实时均值引力 / 乖离率 (Real-time Bias)
计算当前**实时价格**偏离中期价值中枢的距离，作为观测指标输出给上层分析模块，但不直接参与 `tag_today` 判定。
* **乖离率公式**：$$Bias_{20}(t) = \frac{P_{realtime} - EMA_{20}(t)}{EMA_{20}(t)} \times 100\%$$

### 2.5 成交量结构 / Volume Regime
本节给出 `tag_today` 和 `flow_status_tag` 共用的成交量确认因子。默认基于已收盘完整交易日（T-1 锚）；若港股 15:00 后或盘后已有当天快照，则允许使用当天成交额。

#### 2.5.1 关键字段
设 $Amount(t)$ 为当日成交额（优先使用 `turnover/amount`，缺失时才回退 `volume`），定义：

- $A_{target}$ = 待判定日成交额（盘后当天或 T-1）
- $A_{ema5}$ = 待判定日前历史成交额的 5 日 EMA 基准
- $A_{ema20}$ = 待判定日前历史成交额的 20 日 EMA 基准

#### 2.5.2 核心比值
- $R_{target/ema5} = A_{target} / A_{ema5}$
- $R_{target/ema20} = A_{target} / A_{ema20}$
- $R_{ema5/ema20} = A_{ema5} / A_{ema20}$

#### 2.5.3 成交量 regime 分类（极端值开关）
为避免标签组合爆炸，成交量 regime 只保留 **3 档**，并且只有进入“放量/缩量”极端档时才参与 `flow_status_tag` 合成，中性档完全不影响标签：

- **放量**：满足任一条件：
  - 双确认：$R_{target/ema20} \geq 1.5$ 且 $R_{target/ema5} \geq 1.3$
  - 短期极端：$R_{target/ema5} \geq 1.5$
- **缩量**：满足任一条件：
  - 双确认：$R_{target/ema20} \leq 0.6$ 且 $R_{target/ema5} \leq 0.7$
  - 短期极端：$R_{target/ema5} \leq 0.6$
- **中性**：其余所有情况，不参与 `flow_status_tag` 合成

阈值说明：

- 5 日 EMA 更重视近期成交环境，20 日 EMA 用于确认相对中期是否也进入极端区间。
- 双确认用于降低误报；短期极端用于捕捉刚启动或刚枯竭的量能异动，但阈值更高。
- 阈值由 `Settings` 配置，默认放量为双确认 `1.5/1.3` 或短期极端 `1.5`，缩量为双确认 `0.6/0.7` 或短期极端 `0.6`。

## 3. 量化标签生成规则 (Tagging Logic)
系统需在每日盘中触发时，根据包含实时价格的数学计算结果，按“价格结构 + target 成交量结构”联合生成以下策略标签，并输出至 AI 研报中：

### 3.1 右侧趋势策略：多周期共振 (MTF)
用于在常态市场中进行胜率极高的顺势判定。
* **【主升浪加速：长短共振】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$ 且 $A_5 > 0$
    * **量能确认**：目标成交额量能 regime 为“放量”且 $R_{ema5/ema20} \geq 1$，视为强确认；若为“中性”则视为常规确认；若为“缩量”则提示动能可疑。
    * **逻辑归因**：中期趋势向好，短期趋势向好，且处于加速爆发期；若过去一日及过去一周成交活跃度抬头，说明真实参与资金扩张，信号质量更高。
* **【主升浪降速：高位震荡/诱多】**：
    * **触发条件**：$V_{20} > 0$ 且 $V_5 > 0$，但 $A_5 < 0$
    * **量能确认**：
      - 放量：偏“高位分歧放大”
      - 缩量：偏“缩量整理”
    * **逻辑归因**：虽然均线绝对值仍在上涨，但上涨速度已严重衰减；需结合 target 量能结构区分是强势换手，还是上行动能不足。
* **【主跌浪加速：空头长短共振】** (补充)：
    * **触发条件**：$V_{20} < 0$ 且 $V_5 < 0$ 且 $A_5 < 0$
    * **量能确认**：若 target 量能 regime 为放量，则视为空头释放更充分。
    * **逻辑归因**：大势向下，短期也向下，且下跌正在加速；若同时量能放大，说明筹码松动和抛压释放更明显。
* **【跌势放缓：左侧建仓观察区】** (补充)：
    * **触发条件**：$V_{20} < 0$ 且 $V_5 < 0$ 且 $A_5 > 0$
    * **量能确认**：
      - 缩量：偏“抛压衰减”
      - 放量：偏“下跌末端激烈换手”
    * **逻辑归因**：虽然仍处于下跌通道，但下跌速度开始收敛；target 量能结构可帮助区分是阴跌衰减，还是底部剧烈换手。

### 3.2 趋势反转策略：均线拐点与交叉 (补充)
用于捕捉趋势刚刚发生反转的早期信号。
* **【短期趋势转多：均线金叉预备】** (补充)：
    * **触发条件**：$V_{20} < 0$（或方向不明）但 $V_5 > 0$
    * **量能确认**：若 target 量能 regime 为放量，则更接近“有效转多”；若为缩量，则仅视为弱修复；中性则需观察后续。
    * **逻辑归因**：中期趋势仍在调整，但短期均线已率先抬头向上；需由 target 量能结构确认是否有真实资金介入。
* **【短期趋势转空：均线死叉预备】** (补充)：
    * **触发条件**：$V_{20} > 0$ 但 $V_5 < 0$
    * **量能确认**：若 target 量能 regime 为放量，则偏“高位派发/分歧扩大”；若为缩量，则更偏正常回撤。
    * **逻辑归因**：中期趋势依然向好，但短期资金开始撤离；target 量能结构有助于区分是高位分歧，还是良性回调。

### 3.3 实际落地建议

最终 `tag_today` 不应只返回单一方向词，而应结合"放量或缩量"（忽视中性）进行二次研判，输出 `tag_combined` 结论。**中性量能不追加任何修饰，直通原始 `tag`。**

| 组合 | 结论 | 主力行为 | 操作建议 |
|------|------|----------|----------|
| **主升浪加速 + 放量** | ✅ 真突破，主升浪开启 | 资金大规模进场，多空一致看多 | 加仓、追涨 |
| **主升浪加速 + 缩量** | ✅ 极致控盘加速，涨得更猛 | 主力锁仓，无抛压，想拉多少拉多少 | 死拿不动，不要做 T |
| **主升浪降速 + 放量** | ❌ 真出货，顶部确认 | 主力高位派发筹码，散户接盘 | 立刻止盈，清仓跑路 |
| **主升浪降速 + 缩量** | ⚠️ 强势整理，还有新高 | 主力洗盘未出货，清洗获利盘 | 持有，回调加仓 |
| **主跌浪加速 + 放量** | ❌ 真出货，下跌刚开始 | 主力不计成本砸盘出逃，恐慌盘涌出 | 立刻止损，不要抄底 |
| **主跌浪加速 + 缩量** | ✅ 假破位洗盘，黄金坑 | 主力对倒砸盘吓散户，自己在下面接 | 越跌越买，重仓抄底 |
| **跌势放缓 + 缩量** | ✅ 抛压枯竭，底部确认 | 散户割肉完毕，无人再卖，主力开始吸筹 | 左侧分批建仓 |
| **跌势放缓 + 放量** | ⚠️ 多空分歧，还会震荡 | 有资金进场，但空头未出完，需继续磨底 | 观望，等缩量再买 |
| **短期转多 + 放量** | ✅ 有效转多，资金认可 | 真实资金介入，短期反弹可信度高 | 轻仓介入，等 V20 转正确认 |
| **短期转多 + 缩量** | ⚠️ 弱修复，量能不足 | 短期均线抬头但无量支撑，技术性反弹 | 观望为主，不追高 |
| **短期转空 + 放量** | ❌ 真回调，还有下跌空间 | 资金出逃，短期趋势走坏 | 减仓，等回调结束再接 |
| **短期转空 + 缩量** | ✅ 洗盘回调，黄金坑 | 主力压盘洗盘，未出货 | 回调加仓，越跌越买 |

> **缩量特别说明**：缩量信号往往反直觉——"极致控盘加速"、"强势整理"、"假破位黄金坑"背后逻辑均指向**主力筹码高度集中、散户筹码不足形成有效抛压**。命中缩量时需优先用量化比值（`R_target_ema5` / `R_target_ema20`）确认缩量真实性，再结合 `A5` 方向做最终判断。
>
> **代码映射**：`tag_combined` 字段由 `calculate_ema_derivatives` 返回，仅在 `volume_regime ∈ {放量, 缩量}` 时合成；中性时 `tag_combined == tag`。


## 4. 当前盘口定性规则 (`flow_status_tag`)

`tag_today` 偏技术结构，回答“今天趋势形态是什么”；`flow_status_tag` 偏盘口交易状态，回答“今天这根 K 线背后的资金和成交是否认可这个趋势”。该字段会进入研报 prompt 的 `当前盘口定性`，因此应避免只输出“主力流入/流出”，而要合成：

1. `_aggregate_hk_capital_flow_from_df(flow_df, window_days)` 输出的窗口资金流结构
2. `calculate_ema_derivatives(df, current_price)` 输出的 `V5 / V20 / A5 / Bias20 / tag`
3. 目标交易日成交量结构：`volume_target`、`volume_ema5`、`volume_ema20`

说明：`analyze_capital_flow` 读取的是 `get_capital_distribution` 的盘中大/中/小单分布，更适合即时盘口解释；`_aggregate_hk_capital_flow_from_df` 读取的是 `get_capital_flow_history` 的历史资金流，和单股研报里的 `近5日/近10日/近90日资金` 是同一套口径。为了避免 `flow_status_tag` 同时混用两套资金定义，本规范统一使用 `_aggregate_hk_capital_flow_from_df`。

口径说明（重要）：

- **价格/趋势侧**反映当下：`price_change_pct / v5 / v20 / a5` 都包含盘中 `current_price`，是实时口径。
- **成交量侧反映 target**：默认使用 T-1 完整交易日；若调用方确认当天成交额已具备可比性（例如港股 15:00 后或盘后），可使用当天快照。无论哪种情况，都不做“盘中折算/预计全天成交量”。
- **资金流侧反映窗口**：`_aggregate_hk_capital_flow_from_df` 取的是 `get_capital_flow_history` 的 1D / 5D / 20D 聚合，同样不依赖盘中数据。
- 因此 `flow_status_tag` 是“今日价格行为 + target 量能结构 + 窗口资金流”的组合；15:00 前通常自带 1 天量能滞后，15:00 后或盘后可使用当天成交额以提高同步性。

### 4.1 设计原则：极端值才参与

为避免“6 种价格趋势 × 5 档量能 × 3 种资金流方向”的组合爆炸，本规范采用**开关式叠加**：

- `tag_today` 已经覆盖了 6 种价格趋势形态，本身已可独立交付。
- `flow_status_tag` 的默认值就是 `tag_today` 加上一段窗口资金流补语，**不主动改写趋势结论**。
- 只有当 target 量能进入 **放量** 或 **缩量** 极端档（见 §2.5.3 双确认/短期极端阈值）时，才追加 `+【放量】` 或 `+【缩量】` 补语；并且在 3 种特定组合下，**覆盖**为更强的盘口定性。
- 中性量能完全不影响标签，相当于这一信号“没开”。

### 4.2 输入字段

建议合成函数使用以下输入：

- `price_change_pct`：今日涨跌幅（实时）
- `main_in_flow_1d / total_in_flow_1d`：最近 1 个交易日主力净流和整体净流
- `main_in_flow_5d / total_in_flow_5d`：最近 5 个交易日主力净流和整体净流
- `main_in_flow_20d / total_in_flow_20d`：最近 20 个交易日主力净流和整体净流
- 上述资金流字段统一来自 `_aggregate_hk_capital_flow_from_df`
- `tag_today`：来自 `calculate_ema_derivatives`，已经包含 V5/V20/A5 综合后的趋势形态
- `v5 / v20 / a5`：来自 `calculate_ema_derivatives`，用于覆盖规则
- `volume_regime`：放量 / 中性 / 缩量，三档（§2.5.3 双确认/短期极端阈值）
- `volume_ratio_target_ema5 / volume_ratio_target_ema20 / volume_ratio_ema5_ema20`：仅用于解释补语

输出：

- `flow_status_tag`：可直接放入 prompt 的盘口定性
- `volume_regime`：放量 / 中性 / 缩量
- 三个比值字段透传给研报，便于人工复核

### 4.3 合成规则（仅 3 条覆盖 + 1 条默认）

按下列优先级评估，命中第一条即返回；都不命中则走默认。

**覆盖 1 ｜放量破位**

- 条件：`volume_regime == 放量` 且 `price_change_pct < 0` 且 `v5 < 0` 且 `v20 <= 0` 且“主力 1D 净流出 且 整体 1D 净流出”
- 输出：`【放量下跌：破位风险/资金共振流出】`

**覆盖 2 ｜放量诱多**

- 条件：`volume_regime == 放量` 且 `price_change_pct > 0` 且“主力 1D 净流出 但 整体 1D 净流入”
- 输出：`【放量诱多：小单承接/主力派发】`

**覆盖 3 ｜缩量跌不动**

- 条件：`volume_regime == 缩量` 且 `price_change_pct < 0` 且 `v5 < 0` 且 `a5 >= 0`（下跌速度不再恶化）且“主力 1D 未净流出”
- 输出：`【缩量下跌：抛压衰减/跌不动】`

**默认 ｜趋势直通 + 量能补语 + 资金流补语**

- 主体：`tag_today` 原样输出（已经表达了 6 种趋势之一）
- 量能补语：`volume_regime == 放量` → `+【放量】`；`volume_regime == 缩量` → `+【缩量】`；中性不追加
- 资金流补语：基于 1D / 5D 主力与整体净流方向，输出一句简短描述，例如 `主力近5日净流入、近1日转流出`

### 4.4 建议标签格式

`flow_status_tag` 统一为“主标签 + 量能补语 + 资金流补语”，三段都可省略，但主标签必填。示例：

- `【放量下跌：破位风险/资金共振流出】target 成交额打过 EMA5/EMA20 极端阈值，今日V5/V20同向下行，主力与整体1D双双净流出`
- `【放量诱多：小单承接/主力派发】昨日成交显著放大，今日价格上涨但主力1D净流出、整体1D净流入`
- `【缩量下跌：抛压衰减/跌不动】target 成交额低于 EMA5/EMA20 极端阈值，今日V5仍弱但A5回升，主力1D未同步流出`
- `【主升浪加速：长短共振】+【放量】 主力近5日持续净流入，近1日净流入加速`
- `【跌势放缓：左侧建仓观察区】+【缩量】 主力近5日转为净流入，整体仍小幅净流出`
- `【主升浪降速：高位震荡/诱多】 主力近5日净流入但近1日转为净流出，需警惕高位分歧`（量能中性，仅输出趋势 + 资金流）

## 5. 给 Trae 的开发指令 (Implementation Directives)

1.  **修改核心函数**：在 `src/analysis/futu_math_indicator.py` 中更新核心计算函数为 `calculate_ema_derivatives(df: pd.DataFrame, current_price: float) -> dict:`。
2.  **数据拼接逻辑**：如果 `df` 中最后一行的数据日期不是今天，则需要将 `current_price` 作为一个新行（代表今天的最新收盘价）拼接到 `df` 中，或者直接用 `current_price` 更新今天已有的收盘价，确保 `EMA` 计算包含了最新的价格动量。
3.  **核心代码实现要求**：
    ```python
    import pandas as pd

    # 0. 拼接或更新最新价格
    # 假设 df 已经包含历史数据，需处理当前价格 current_price
    # df 最后一行的 close 会被赋予或更新为 current_price 以反映盘中实时状态
    
    # 1. 计算机构级 EMA
    df['EMA5'] = df['close'].ewm(span=5, adjust=False).mean()
    df['EMA20'] = df['close'].ewm(span=20, adjust=False).mean()

    # 2. 计算一阶导数 V (百分比变化率)
    df['V5'] = df['EMA5'].pct_change() * 100
    df['V20'] = df['EMA20'].pct_change() * 100

    # 3. 计算二阶导数 A (速度的差分)
    df['A5'] = df['V5'].diff()

    # 4. 计算实时 Bias 乖离率（仅观测，不参与 tag 判定）
    df['Bias20'] = (df['close'] - df['EMA20']) / df['EMA20'] * 100

    # 5. 计算成交额 regime（优先 turnover/amount，3 档开关，EMA5/EMA20 基准）
    # 注意：15:00 前不使用盘中成交额；15:00 后或盘后可使用当天 turnover。
    closed_amount = df['turnover'].dropna()
    amount_target = current_turnover if current_turnover else closed_amount.iloc[-1]
    amount_baseline = closed_amount if current_turnover else closed_amount.iloc[:-1]
    amount_ema5 = amount_baseline.ewm(span=5, adjust=False).mean().iloc[-1]
    amount_ema20 = amount_baseline.ewm(span=20, adjust=False).mean().iloc[-1]
    r_target_ema5 = amount_target / amount_ema5
    r_target_ema20 = amount_target / amount_ema20

    if (r_target_ema20 >= 1.5 and r_target_ema5 >= 1.3) or r_target_ema5 >= 1.5:
        volume_regime = "放量"
    elif (r_target_ema20 <= 0.6 and r_target_ema5 <= 0.7) or r_target_ema5 <= 0.6:
        volume_regime = "缩量"
    else:
        volume_regime = "中性"
    ```
