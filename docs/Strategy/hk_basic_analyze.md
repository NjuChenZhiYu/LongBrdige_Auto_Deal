# 港股单股研报：基本面与买方视角重构说明

本文用于约束 `src/services/llm_analyst.py` 及相关数据获取逻辑（如 `hk_basic_finance_data`），确保传入大模型的【基本面与估值快照】符合“买方真实定价逻辑”，彻底摒弃传统静态指标对新经济/科技股的估值扭曲。

## 1. 背景与核心痛点（买方真相）

过去的 Prompt 与数据提取存在三大“盲区”，需要通过本次重构予以纠正：

1. **盈利指标的静态扭曲**：
   过去的系统只看表内净利润（`net_profit`）。但科技股（尤其是 18C 特专科技股）早期多为账面亏损，港股对科技股真正定价的锚是**“经调整净利润（Non-IFRS）”**和**“经营性现金流”**。例如极智嘉（02590）已经实现了 4000 多万的经调整盈利和正向现金流，单纯看静态净利润会产生巨大误判。
2. **估值锚的错配（BPS/PB vs PS）**：
   上一轮优化中强制要求使用“每股净资产(BPS)”和“PB”推演真实安全边际。这套框架只适用于银行、煤炭等重资产股。极智嘉是典型的硬科技/软件算法+硬件的轻资产龙头，核心资产（7万台机器人的调度数据、生成式仿真技术、海外高毛利订单）根本进不了资产负债表。对于这类科技股，**全球通用的估值锚是 PS（市销率）**。极智嘉 6.8 倍的 PS 远低于行业平均的 20+ 倍，这才是真正的低估。
3. **量化引擎的微观短视（误判踩踏）**：
   过去的系统看到近 10 日股价阴跌、量价资金流为负，就贴上“机构出逃 / 踩踏砸盘”的标签。系统缺乏“宏观常识”与筹码认知：极智嘉 2025 年上市，基石投资者有 6 个月的锁仓期，外面流通盘极其微小。这种阴跌根本不是机构跑路，而是**打新散户和微观量化盘在流动性枯竭情况下的互砍**。同时，纯技术面根本看不到“特朗普访华”和“SpaceX IPO”等即将引爆科技股的宏观核弹。

## 2. 核心功能模块与接口映射 (重构方向)

> 模块 A（`get_stock_filter`）与模块 C（传统板块对比）暂不启用；当前仅保留模块 B（资金流），行业相对估值改为“联网对标指令”由大模型执行。

### 模块 B：微观资金流向与流动性透视 (Smart Money Flow)
**突破盲区**：识别真实的“机构行为”与“流动性枯竭”，引入筹码结构常识。
* **调用接口**：富途 `get_capital_flow`。
* **目标字段**：
  - `in_flow` (整体净流入) vs `main_in_flow` (主力大单净流入)。
* **执行逻辑**：不能单纯看资金净流出。若整体阴跌且量能极度萎缩（结合次新股基石锁仓期），即便总资金流为负，也应判定为“流动性不足导致的散户互砍”，而不是大机构踩踏；若股价下跌但 `main_in_flow` 累计为正，应标记为“主力隐蔽吸筹”。

### 行业对标与相对估值（替代方案：联网查询）
1. **废弃传统板块估值获取**：在 Python 实现中，删掉 `get_plate_stock` / `get_stock_filter` 这类板块估值对比逻辑；`get_owner_plate` 仅保留用于展示“所属板块”文本，不参与行业估值计算。
2. **在 Prompt 中激活搜索与智能对标**：加入明确的联网对标指令，由模型检索全球可比公司并做 PS 对比。

【行业对标与相对估值指令】
- 严禁使用笼统的“机器人概念”均值。
- 请利用你的联网搜索功能，在全球市场（特别是美股）寻找与该标的商业模式最接近的 1-2 家对标公司（如 Symbotic / AutoStore）。
- 获取对标公司的实时或近期 PS（市销率）估值，作为行业天花板/基准，与当前标的 PS(TTM) 做比较。
- 给出结论：当前标的是“稀缺性溢价”还是“严重低估”。

## 4. LLM 输出结构与分析范式（与代码一致）

请按以下结构输出（Markdown）：
1. **核心结论**（先给方向，40-80字）
2. **基本面与估值透视**（中长期推演，150-250字）
   * 严禁单纯罗列数据，必须穿透财务快照形成定价逻辑。
   * **重塑估值锚**：对于轻资产科技股（18C等），**严禁使用 BPS/PB 评估安全边际**，必须使用 **PS (市销率)**；行业可比估值需通过联网检索全球对标公司获取，不再使用本地板块均值。
   * **筹码与流动性**：结合【总/流通市值】与次新股特征（如基石锁仓期）定性当前的盘口流动性，准确识别是“机构出逃”还是“流动性枯竭下的散户/微观量化互砍”。
3. **技术面证据链**（短期当日信号 + 10日风险收益 + 10日筹码分布 + 中期形态，180-260字）
4. **交易计划**（入场条件、止损位、失效条件，80-120字）
5. **核心风险/证伪条件**（除常规止损外，必须给出1条可导致逻辑瞬间崩塌的非结构化风险触发，如宏观事件/产业政策，40-80字）
