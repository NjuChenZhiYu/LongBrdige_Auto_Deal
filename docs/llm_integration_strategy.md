# LLM 智能分析功能集成策略

## 概述

本文档描述 LongBridge 自动交易系统中 AI 大模型（LLM）的集成策略和功能设计。通过与 Kimi/Moonshot API 的对接，系统能够在股票价格异动时提供 AI 驱动的深度分析，并自动生成每日市场研报。

## 功能特性

### 1. 实时股票异动 AI 分析 (`llm_analyst`)

> **已移除 (REMOVED)**：为彻底防止 token 消耗过大，实时单股 AI 分析功能已被**永久移除**。仅保留每日定时或手动触发的批量市场研报功能。

### 2. 每日市场研报自动生成

系统定时聚合全天所有触发告警的股票，生成 300 字的市场日报。

**触发时间：**
- **美股日报**：22:50 CST（盘前） / 07:50 CST（盘后）
- **港股日报**：10:00 CST（盘中） / 15:20 CST（盘中）

**数据源**：当前触发价格异动告警的股票列表

**研报内容结构：**
1. **市场整体研判**：基于涨跌分布判断市场情绪（乐观/谨慎/观望）
2. **板块/热点分析**：识别是否有明显的板块集中异动特征
3. **重点个股点评**：挑选 2-3 只异动最剧烈或最具代表性的股票进行简要点评
4. **次日展望**：基于当前市场状态给出简要的投资建议或风险提示

**期权异动报告（特别关注）：**
- **触发方式**：每日定时（22:50）
- **数据源**：盘中触发的远期期权（LEAPS）异动数据
- **分析维度**：机构资金流向识别（建仓/平仓）、隐含波动率（IV）变化分析、潜在事件定价

### 3. 信号记录 (`signal_recorder`)

- 记录所有触发的价格异动信号
- 支持按市场类型（US/HK）筛选
- 日报生成后自动清理

### 4. 前端手动触发研报生成

在 Web 监控界面提供按钮，允许用户随时基于当前自选股行情生成 AI 分析报告：

**功能入口：**
- 美股市场标签页："生成美股研报" 按钮
- 港股市场标签页："生成港股研报" 按钮

**使用场景：**
- 盘中心情研判
- 自选股池整体分析
- 临时决策支持

## 技术架构与实现

### 1. 核心模块与目录结构

```
src/
├── api/
│   └── llm_deprecated.py   # [已废弃] 旧版单股 LLM 分析客户端
├── services/
│   ├── llm_analyst.py      # 研报生成服务
│   └── signal_recorder.py  # 信号记录器（支持股票和期权）
├── monitor/
│   └── utils.py            # 告警处理（仅基础通知，移除 LLM）
└── web/
    ├── app.py              # Web 服务（新增研报生成路由）
    └── templates/
        └── index.html      # 前端界面（新增 AI 按钮）
```

### 2. 数据流

```
股票价格更新
    ↓
触发阈值检查 (handle_quote_alert)
    ↓
├─→ 记录到 SignalRecorder
└─→ 发送实时告警（纯文本，不含 AI 分析）
└─→ 等待定时任务聚合

定时任务 (22:50 / 07:50 / 10:00 / 15:20), 前端触发时也会执行
    ↓
读取实时的告警股票列表（HK / US）
    ↓
调用 LLM 生成聚合研报 (generate_stock_report)
    ↓
推送完整市场日报
```

### 3. 详细实现

#### 3.1 前端界面 (`src/web/templates/index.html`)

**AI 功能区**：
```html
<h2>🤖 AI 智能分析</h2>
<form action="/generate_ai_report" method="POST">
    <input type="hidden" name="market_type" value="US/HK">
    <button type="submit">生成美股/港股研报</button>
</form>
```

#### 3.2 后端路由 (`src/web/app.py`)

```python
@app.route('/generate_ai_report', methods=['POST'])
def generate_ai_report():
    market_type = request.form.get('market_type', 'US')
    asyncio.run(llm_analyst.generate_stock_report(market_type))
```

#### 3.3 LLM 服务 (`src/services/llm_analyst.py`)

**系统提示词（System Prompt）**：

```
你是一位资深的股票市场分析师，擅长宏观经济研判和个股异动分析。
要求：
1. 市场整体研判：基于涨跌分布和平均涨跌，给出市场整体情绪判断
2. 板块/热点分析：识别是否有明显的板块集中异动特征
3. 重点个股点评：挑选2-3只异动最剧烈或最具代表性的股票进行简要点评
4. 次日展望：基于当前市场状态，给出简要的投资建议或风险提示
5. 语言风格要专业、有洞察，直接给出结论
6. 使用 Markdown 格式输出，字数控制在 300 字左右
```

### 4. API 设计

#### LLM 分析接口
```python
async def analyze_stock_alert(
    symbol: str,           # 股票代码
    last_price: float,     # 最新价格
    change_rate: float,    # 涨跌幅
    prev_close: float,     # 昨收价
    volume: int = 0,       # 成交量
    turnover: float = 0.0, # 成交额
    market_type: str = "US", # 市场类型
) -> Optional[str]:
    """返回 AI 分析文本或 None"""
```

#### 研报生成接口
```python
async def generate_stock_report(
    market_type: str = "US"  # "US" 或 "HK"
) -> Optional[str]:
    """生成并推送市场日报"""
```

## 部署与配置

### 1. 环境变量配置

在 `config/.env` 文件中配置：

```bash
# ===========================================
# 大模型 AI 分析配置（Kimi / Moonshot）
# ===========================================

# API Key（必填）
LLM_API_KEY=sk-your-api-key-here

# API 地址
LLM_BASE_URL=https://api.moonshot.cn/v1
# 或者 OpenAI: https://api.openai.com/v1

# 模型名称（可选：kimi-k2.5 / kimi-latest / gpt-4）
LLM_MODEL=kimi-k2.5
```

### 2. 阈值配置

在 Web 界面或 `config/symbols.yaml` 中设置：

```yaml
thresholds:
  price_change: 5.0  # 价格波动阈值（百分比）
```

## 性能与限制

### API 调用限制
- 每次分析约消耗 500-800 tokens
- 研报生成约消耗 1000-1500 tokens
- 建议监控 API 用量避免超额

### 延迟考量
- 单次分析：1-3 秒（网络依赖）
- 日报生成：3-5 秒（聚合多只股票）
- 失败时自动降级，不影响主流程

### 错误处理
- API Key 无效：静默跳过，不中断监控
- 网络超时：自动重试一次，失败则返回 None
- 响应格式异常：记录日志，返回降级内容
