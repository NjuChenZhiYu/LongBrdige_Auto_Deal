# LLM 智能分析功能集成策略

## 概述

本项目集成了大语言模型（LLM）能力，为量化交易监控系统提供智能化的股票分析和研报生成功能。通过与 Kimi/Moonshot API 的对接，系统能够在股票价格异动时提供 AI 驱动的深度分析，并自动生成每日市场研报。

## 功能特性

### 1. 实时股票异动 AI 分析

当监控的股票触发价格阈值告警时，系统自动调用 LLM 进行实时分析：

**输入数据维度：**
- 标的代码与市场价格
- 涨跌幅与涨跌方向
- 成交量与成交额
- 昨收价作为基准

**AI 分析维度：**
- **技术面分析**：结合成交量判断是放量突破还是缩量回调
- **异动归因**：分析可能的驱动因素（大盘联动、板块效应、个股消息等）
- **市场情绪**：解读当前多空力量对比
- **操作建议**：提示投资者关注的风险点或机会点

**输出格式：**
- 150-200 字的中文专业分析
- 直接、简洁、 actionable 的结论
- 自动追加到钉钉/飞书告警消息中

### 2. 每日市场研报自动生成

系统定时聚合全天所有触发告警的股票，生成 300 字的市场日报。

**触发时间：**
- 美股日报：22:50（盘后）
- 港股日报：07:50（盘前）

**研报内容结构：**
1. **市场整体研判**：基于涨跌分布判断市场情绪（乐观/谨慎/观望）
2. **板块/热点分析**：识别是否有明显的板块集中异动
3. **重点个股点评**：挑选 2-3 只最具代表性的股票进行点评
4. **次日展望**：基于当前市场状态给出投资建议或风险提示

**研报统计指标：**
- 异动标的总数
- 上涨/下跌家数分布
- 平均涨跌幅

### 3. 前端手动触发研报生成

在 Web 监控界面提供按钮，允许用户随时基于当前自选股行情生成 AI 分析报告：

**功能入口：**
- 美股市场标签页："生成美股研报" 按钮
- 港股市场标签页："生成港股研报" 按钮

**使用场景：**
- 盘中心情研判
- 自选股池整体分析
- 临时决策支持

## 技术架构

### 核心模块

```
src/
├── api/
│   └── llm.py              # LLM API 客户端封装
├── services/
│   ├── llm_analyst.py      # 研报生成服务
│   └── signal_recorder.py  # 信号记录器（支持股票和期权）
├── monitor/
│   └── utils.py            # 告警处理（集成 LLM 分析）
└── web/
    ├── app.py              # Web 服务（新增研报生成路由）
    └── templates/
        └── index.html      # 前端界面（新增 AI 按钮）
```

### 数据流

```
股票价格更新
    ↓
触发阈值检查 (handle_quote_alert)
    ↓
├─→ 记录到 SignalRecorder
├─→ 调用 LLM 分析 (llm_analyzer.analyze_stock_alert)
├─→ 发送实时告警（含 AI 分析）
└─→ 等待定时任务聚合

定时任务 (22:50 / 07:50)
    ↓
读取 SignalRecorder 中的当日告警
    ↓
调用 LLM 生成聚合研报 (generate_stock_report)
    ↓
推送完整市场日报
```

## 配置说明

### 环境变量配置

在 `config/.env` 文件中配置：

```bash
# ===========================================
# 大模型 AI 分析配置（Kimi / Moonshot）
# ===========================================

# Kimi API Key（必填）
LLM_API_KEY=sk-your-api-key-here

# Kimi API 地址（默认不用改）
LLM_BASE_URL=https://api.moonshot.cn/v1

# 模型名称（可选：kimi-k2.5 / kimi-latest）
LLM_MODEL=kimi-k2.5
```

### 阈值配置

在 Web 界面或 `config/symbols.yaml` 中设置：

```yaml
thresholds:
  price_change: 5.0  # 价格波动阈值（百分比）
```

## API 设计

### LLM 分析接口

```python
async def analyze_stock_alert(
    symbol: str,           # 股票代码
    last_price: float,     # 最新价格
    change_rate: float,    # 涨跌幅
    prev_close: float,     # 昨收价
    volume: int = 0,       # 成交量
    turnover: float = 0.0, # 成交额
    market_type: str = "US", # 市场类型
) -> Optional[str]:
    """返回 AI 分析文本或 None"""
```

### 研报生成接口

```python
async def generate_stock_report(
    market_type: str = "US"  # "US" 或 "HK"
) -> Optional[str]:
    """生成并推送市场日报"""
```

### Web 接口

```
POST /generate_ai_report
参数：market_type ("US" 或 "HK")
功能：手动触发生成 AI 研报
```

## 性能与限制

### API 调用限制
- 每次分析约消耗 500-800 tokens
- 研报生成约消耗 1000-1500 tokens
- 建议监控 API 用量避免超额

### 延迟考量
- 单次分析：1-3 秒（网络依赖）
- 日报生成：3-5 秒（聚合多只股票）
- 失败时自动降级，不影响主流程

### 错误处理
- API Key 无效：静默跳过，不中断监控
- 网络超时：自动重试一次，失败则返回 None
- 响应格式异常：记录日志，返回降级内容
