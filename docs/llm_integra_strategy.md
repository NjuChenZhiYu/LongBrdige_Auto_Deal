# LLM 集成策略文档

## 概述

本文档描述 LongBridge 自动交易系统中 AI 大模型（LLM）的集成策略和功能设计。

## 功能架构

### 1. 核心功能模块

#### 1.1 AI 研报生成 (`llm_analyst`)

**美股/港股日报**
- **触发方式**：
  - 前端按钮手动触发 (`/generate_ai_report`)
  - 定时任务自动触发 (每日 22:50 和 07:50)
- **数据源**：当日触发价格异动告警的股票列表
- **分析维度**：
  - 市场整体情绪判断（基于涨跌分布）
  - 板块/热点分析
  - 重点个股点评（2-3只代表性股票）
  - 次日展望和投资建议

**期权异动报告**
- **触发方式**：每日定时（22:50）
- **数据源**：盘中触发的远期期权（LEAPS）异动数据
- **分析维度**：
  - 机构资金流向识别（建仓/平仓）
  - 隐含波动率（IV）变化分析
  - 潜在事件定价（财报、临床数据等）

#### 1.2 信号记录 (`signal_recorder`)

- 记录所有触发的价格异动信号
- 支持按市场类型（US/HK）筛选
- 日报生成后自动清理

### 2. 技术实现

#### 2.1 前端界面

**位置**：`src/web/templates/index.html`

**AI 功能区**：
```html
<h2>🤖 AI 智能分析</h2>
<form action="/generate_ai_report" method="POST">
    <input type="hidden" name="market_type" value="US/HK">
    <button type="submit">生成美股/港股研报</button>
</form>
```

#### 2.2 后端路由

**位置**：`src/web/app.py`

```python
@app.route('/generate_ai_report', methods=['POST'])
def generate_ai_report():
    market_type = request.form.get('market_type', 'US')
    asyncio.run(llm_analyst.generate_stock_report(market_type))
```

#### 2.3 LLM 服务

**位置**：`src/services/llm_analyst.py`

**配置参数**（`config/settings.py`）：
- `LLM_API_KEY`: OpenAI 兼容 API Key
- `LLM_BASE_URL`: API 基础 URL
- `LLM_MODEL`: 模型名称（如 gpt-4, kimi-k2.5 等）

**系统提示词（System Prompt）**：

美股/港股日报：
```
你是一位资深的股票市场分析师，擅长宏观经济研判和个股异动分析。
要求：
1. 市场整体研判：基于涨跌分布和平均涨跌，给出市场整体情绪判断
2. 板块/热点分析：识别是否有明显的板块集中异动特征
3. 重点个股点评：挑选2-3只异动最剧烈或最具代表性的股票进行简要点评
4. 次日展望：基于当前市场状态，给出简要的投资建议或风险提示
5. 语言风格要专业、有洞察，直接给出结论
6. 使用 Markdown 格式输出，字数控制在 300 字左右
```

### 3. 部署配置

#### 3.1 环境变量

在 `.env` 文件中配置：
```bash
# LLM Configuration
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4
```

#### 3.2 定时任务

**美股日报**：
- 22:50 CST（美股开盘前）
- 07:50 CST（美股收盘后）

**港股日报**：
- 09:00 CST（港股开盘前）
- 16:10 CST（港股收盘后）
