# 美股远期期权 (LEAPS) 异动监控与 AI 投研分析系统 (v2.0)

## 1. 策略概述
基于长桥 (LongPort) Python SDK 监听自选期权的盘口异动，并将异动数据汇总。在指定时间点，系统将调用大模型 (LLM) 对当日异动数据进行深度解读与逻辑推演，最终通过钉钉 Webhook 推送具备投研价值的分析报告。

**监控标的：** 从 `symbols.yaml` 动态读取 (例: `LEGN270115C22500`, 行权价 22.50; `RXRX261120C3500`, 行权价 3.50)。

## 2. 核心监控逻辑 (数据采集层)
* **策略 A (IV 偏离)**：记录 `current_iv > baseline_iv * 1.3` 的瞬间。
* **策略 B (Smart Money)**：记录当日 `volume > open_interest * 0.20` 的标的。
* **策略 C (Delta 跨越)**：记录 `delta` 向上突破 0.5 (虚转实) 的瞬间。
* **动作**：盘中触发以上任何条件时，**不立即发送钉钉**，而是将带有时间戳的异动快照 (Snapshot) 存入内存中的 `daily_signals_list`。

## 3. 大模型解读与推送机制 (AI Interpretation Layer)
系统在以下两个时间点触发 AI 分析流水线：
* **时间点 A (北京时间 22:50)**：美股开盘初段异动汇总。
* **时间点 B (北京时间 07:50)**：全天数据沉淀与收盘复盘。



### 3.1 AI 推理逻辑 (给 Trae 的代码要求)
在到达定点时间时，执行以下异步流程：
1. **数据组装**：提取 `daily_signals_list` 中的所有记录，将其格式化为一段结构化的 JSON 或文本字符串。
2. **LLM 调用**：使用兼容 OpenAI 格式的异步客户端 (或长桥内置的 LLM SDK)，调用大模型 (如 Kimi / Gemini)。
3. **系统提示词 (System Prompt)**：
   > "你是一位华尔街资深的生物医药期权交易员。我将提供今天盘中触发异动报警的远期期权 (LEAPS) 数据。
   > 请根据这些数据（如 IV 飙升、成交量激增突破 OI 的 20%、Delta 突破 0.5），为我撰写一份专业的市场复盘报告。
   > 要求：
   > 1. 识别出是否有机构(Smart Money)在大量建仓或平仓。
   > 2. 分析 IV 的变化意味着市场在定价什么潜在事件（如临床数据发布、财报等）。
   > 3. 语言风格要专业、精炼，直接给出结论和潜在的交易风险。
   > 4. 使用 Markdown 格式输出，字数控制在 300 字以内。"
4. **钉钉推送**：将 LLM 返回的 Markdown 文本，直接作为主体内容推送到钉钉 Webhook。

## 4. 容错与工程化规范
1. **清空缓存**：每次定点推送完成后，必须清空当前的 `daily_signals_list`，防止数据重复推给大模型。
2. **LLM 回退机制 (Fallback)**：如果大模型 API 调用超时或失败，系统需捕获异常，并**降级**为直接推送原始的异动数据列表，确保警报不丢失。
3. **异步并发**：必须使用 `asyncio` 和 `aiohttp`，确保长桥的 WebSocket 监听和大模型的 HTTP 请求不会互相阻塞。
